# CSE 592 - Live Coding repository

This repository contains the code we showed live during [CSE 592](https://gpoesia.com/teaching/cse592-fall26/) lectures at UMich. It will be updated as the semester goes.

Homework assignments will also refer to code published here and ask you to use it or modify it.

* `lecture2/` - A* search and heuristics for the N-puzzle
* `lecture4/` - DPLL for SAT solving, and the Lights Out puzzle solved as a SAT problem
* `lecture8/` - Linear regression, Gradient Descent and SGD
* `lecture10/` - Automatic differentiation, ReLU neural network with SGD from scratch
